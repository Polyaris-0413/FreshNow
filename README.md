## 特性

### AI
* 不内置任何 OCR 算法，所有信息全部交由 AI 实时识别
* 支持通过 OpenAI 协议接入模型
* 支持自定义模型思考参数等配置

### 界面
* 使用 Material Design 3 设计
* 动画恰到好处

### 其他
* 无广告、无追踪、无内购
* 支持在线更新
